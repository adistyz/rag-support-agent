# Pelacakan Pesanan

Setiap pesanan yang dikirim mendapatkan nomor resi. Lacak pesanan dengan
memasukkan nomor resi di halaman Lacak Pesanan di website atau aplikasi
Toko Maju.

Status pelacakan diperbarui setiap kali paket berpindah hub kurir. Jika
status tidak berubah lebih dari 3 hari kerja, hubungi customer service
dengan nomor pesanan Anda.
